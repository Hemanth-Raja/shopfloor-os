# Shop-Floor OS

A multi-agent dispatch system for warehouse floors: AI agents plan, robots execute, humans judge.
Open Agent Hackathon 2026, Track 3 (Reasoning Architecture). Work in progress.

## Data
- Synthetic floor map, AGVs, workers, shifts and incident history (generated by `app/data/generate.py`, seed 42).
- UCI AI4I 2020 Predictive Maintenance dataset, CC BY 4.0, DOI 10.24432/C5HS5C.
- OSHA 29 CFR 1910.178, 1910.22 and 1910.147 rule summaries. Source: U.S. Department of Labor (public domain); no endorsement implied.

All people in the data are fictional.
