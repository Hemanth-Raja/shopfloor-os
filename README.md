# Shop-Floor OS

A multi-agent dispatch system for a car assembly plant: AI agents plan, robots execute, humans judge.
Open Agent Hackathon 2026, Track 3 (Reasoning Architecture). Work in progress.

## The plant (fictional)
A car assembly plant with a body shop, paint shop, trim line, powertrain marriage, final assembly and
end-of-line test. A parts supermarket and kitting area feed the line with 16 AGVs (kitting AGVs, tuggers,
body carriers). 79 people work two production shifts and a night maintenance shift. The history covers
13 weeks (20 Jul to 18 Oct 2026), with a target of one car every 90 seconds.

Data lives in four Postgres databases, registered in Zetaris as `sf_fleet`, `sf_hr`, `sf_plant` and `sf_ops`:

| Datasource | Tables |
|---|---|
| sf_fleet | agvs, agv_tasks, agv_telemetry (per minute, last 7 days) |
| sf_hr | workers, certifications, shifts |
| sf_plant | stations, machines, machine_telemetry, production_plan, units, work_orders |
| sf_ops | zones, floor_cells, spill_kits, safety_rules, incidents, andon_events, near_misses, experiments |

```
scripts/start_postgres.sh          # Postgres container on the Zetaris Docker network
scripts/load_data.sh               # generate and (re)load the four databases
python -m app.zetaris register     # first time: create the Zetaris datasources
python -m app.zetaris refresh      # after a reload: pick up new tables and columns
python run.py context --zone FINAL # zone context through Zetaris plus a Nemotron summary
```

## Data sources
- Synthetic: the layout, stations, AGVs, people, rosters, production, incidents, andon pulls, near misses and
  work orders. They are generated by `app/data/generate.py` with seed 42, so every run gives the same data.
- UCI AI4I 2020 Predictive Maintenance dataset, CC BY 4.0, DOI 10.24432/C5HS5C. It is used as telemetry for the
  ten plant machines. AI4I is itself a synthetic dataset modelled on real machine behaviour.
- OSHA 29 CFR 1910.22, 1910.147, 1910.178, 1910.212 and 1910.217 rule summaries, paraphrased. Source: U.S. Department of Labor
  (public domain); no endorsement implied. Two plant rules (robot-cell entry and in-date certification) are our own.

All people, car models and the plant itself are fictional.
