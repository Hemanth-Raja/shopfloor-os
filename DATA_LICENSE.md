# Data licence

The code in this repository is Apache-2.0 (see [LICENSE](LICENSE)). The data falls into two groups:
data we generated, and summaries of third-party public data, each of which keeps its own licence.

## Synthetic data (ours)
Everything about the plant itself is synthetic and generated by [`app/data/generate.py`](app/data/generate.py)
with seed 42: the layout, stations, machines, AGVs, people, certifications, rosters, production, incidents, andon
pulls, work orders, cost figures and the plant SOPs in [`data/seed/plant_sops.json`](data/seed/plant_sops.json).
The people are fictional; any resemblance to real persons is coincidental. This data, the recorded model replies
in [`logs/fixtures/`](logs/fixtures), [`input_examples/`](input_examples) and
[`output_examples/`](output_examples) are released under **Apache-2.0**, the same as the code.
