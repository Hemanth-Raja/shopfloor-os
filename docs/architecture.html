The floor

Simulated assembly hall: 10 stations, 8 AGVs, 24 people, walkways crossing AGV lanes.

Every AGV dispatch is a VDA 5050 v2.0 order; the verifier checks the world changed as predicted and re-plans if not.

Platforms

Zetaris · the data layer

Four Postgres sources federated as sf_fleet, sf_hr, sf_plant, sf_ops, modelled once as the Unified Semantic Layer floor (9 entities with keys). Agents read on a read-only login; Zetaris refuses their writes.

built by code over REST

Meterless Nightshift → NVIDIA Nemotron

The only model provider. One app pinned per model: Nemotron 3 Ultra 550B (planner, analyst, Lab), 3.5 Super VL 120B (coordinator, SQL, handover), 3.5 Lightning 30B (router, monitor, triage, evidence critic). Fallback chains, breakers, hedging; every answer carries a signed receipt verified at call time.
