## Found and fixed by these tests

- **A hedged role skipped its second model.** With Lightning down, the router's hedge never started, so Super VL was never asked; the router reported Nightshift down and the whole incident fell into safe mode. `models._race` now gives the second model its turn when the first fails fast (`tests/test_resilience.py`).
- **Zetaris down at start crashed the server.** It now starts degraded on the offline plant, says so in Health and in the UI, and keeps using Nightshift (`tests/test_fixtures_and_server.py`).

## How the model is chosen for each call

Every agent role has an ordered chain in `config/models.json` (for example the planner: Super VL, then Lightning). For each call, `app/models.py`:
1. drops models the startup self-check found broken or silently served by another model, and models whose context window the prompt would overflow;
2. skips a model whose circuit breaker is open (two failures; one probe after the cooldown);
3. waits for a slot under that model's adaptive concurrency limit (AIMD: halves on errors and very slow replies, grows back slowly), so an overcrowded model is not hammered;
4. retries transient errors (429, 5xx, timeouts, empty replies) with full-jitter backoff inside the incident's deadline, repairs broken JSON before re-asking, then moves to the next model;
5. for latency-critical roles (router, monitor, Sentinel) also asks the next model once the first is slower than 1.5x its median, and takes the first valid answer;
6. if every model fails, the Nightshift-wide breaker opens: the router uses rules, the planner's rules plan (optimal assignment, already critic-checked) is used, and a person approves it.

## When a person does not answer

Covered by `app/autonomy/approval.py` and `tests/test_approval_timeout.py`. Reminder after 2 floor minutes, escalation to the shift manager after 4, and at 6 the agents decide, never in the unsafe direction: a plan held only by the Supervised setting (critic and dry run passed, acting cheaper than waiting) is dispatched and audited; anything that needs a person's judgement (a person entering a hazard, a lapsed certificate, a near miss, safe mode, ESCALATE/SAFE_HOLD) stays in a safe hold, its reserved people and robots are released, and it stays escalated. A late Approve still works. In Advisory mode the clock only reminds.
