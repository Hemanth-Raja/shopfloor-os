Shop-Floor OS

AI agents plan. Robots execute. Humans judge.

A multi-agent incident-response and AGV-dispatch system for a car final-assembly hall. Agents read the plant through Zetaris, reason with NVIDIA Nemotron through Meterless Nightshift and remember with Meterless engines. Code checks every plan against OSHA rules and simulates it before anything moves.

Zetaris USL NVIDIA Nemotron Meterless Nightshift World Model · H-MEM · Markovian Track 3 · Reasoning Architecture

Agents plan

An orchestrator picks the next agent at every hop. Nemotron writes plans that cite the governing OSHA clause.

Robots execute

Only plans that pass the safety critic and a simulated dry run move AGVs, as VDA 5050 orders.

Humans judge

Anything that sends a person into a hazard waits for approval. Every judgement is logged and re-checkable.

The problem · the line stops and people are at risk

75 s

Every stopped minute costs cars

One car leaves final assembly about every 75 s. A missing kit, a stalled AGV, a spill or a weld-robot fault stops the line.

4

The facts are scattered

Fleet manager, HR rosters and certificates, machine telemetry and incident history live in four separate systems.

¼

Many alarms are noise

About a quarter of overheat alarms are sensor noise. Stopping for a false alarm costs as much as missing a real one.

!

Acting can hurt someone

AGVs cross pedestrian walkways; a robot-cell repair needs lockout/tagout. The supervisor has seconds to decide safely.

Our solution · checked, simulated, verified

One view of the plant

Zetaris federates the four sources into one Unified Semantic Layer. The Meterless World Model grounds every id; agents read on a read-only login.

Agents that reason and route

Three Nemotron models via Nightshift: the orchestrator routes, the monitor separates real alarms from noise, the planner cites clauses.

Code decides what is safe

A deterministic OSHA critic, a 60 s dry run in the simulator and a restraint gate check every plan. A person approves anything risky.

It learns, and proves it

H-MEM keeps lessons with outcome feedback; the Lab tests floor changes on history with seeded replays; every model call carries a signed receipt.
